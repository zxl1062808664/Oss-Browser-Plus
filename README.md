OSS Quick Upload 是一款面向阿里云 OSS 的 Windows 桌面客户端。它将常用 Bucket 和目录保存为预设路径，上传时只需选择 OSS 账号和目标路径，不必反复查找或输入完整目录。

项目同时提供 OSS 文件浏览与管理能力（上传、下载、删除、重命名、复制、移动、获取地址、双击预览、文本在线编辑），可按整个账号或预设路径查看内容，适合软件发布、构建产物归档、资源同步和日常文件管理。

## 主要功能

### 上传中心

- 多 OSS 账号管理，账号凭据只需配置一次，Secret 通过系统能力加密保存。
- 为不同账号创建任意数量的常用路径，并添加用途备注，支持一键复制完整 OSS 地址。常用路径支持按分类分组展示，可一键展开 / 折叠。
- 同一批文件可同时上传到多个 OSS 路径。
- **文件夹版本选择**：选择本地项目根目录后弹出树形面板，可多级展开、勾选其中要上传的版本 / 子文件夹（多选），上传后按勾选目录保留层级结构（如 `v1.0/build/app.zip`）。
- **子目录输入框**：可输入一个子目录名，为本次队列在 OSS 目标路径下先套一层文件夹；输入后开始上传前会弹出目标路径确认。
- 独立上传队列展示进度、状态和失败原因，支持取消全部、清空已完成、失败任务手动重试。
- 可配置并发上传任务数与同名文件覆盖 / 跳过策略。
- 运行日志通过页面右上角按钮打开弹窗查看完整记录。

### OSS 文件

- “整个账号”和“预设路径”两种查看模式，支持跨 Region 浏览 Bucket，一键复制当前路径。
- **上传到当前目录**：可直接向正在浏览的目录上传本地文件或整个文件夹（文件夹保留相对结构），右上角按钮实时查看上传进度。
- 下载单个文件、多个文件或完整文件夹，递归保留目录结构。
- **删除 / 重命名**：支持文件和文件夹（文件夹操作会自动递归处理其下所有对象），删除前弹窗确认。
- **复制 / 移动**：选中对象后通过可视化目录选择器浏览并选择目标目录，文件夹连同内容整体转移。
- **获取地址**：生成签名地址（有效期可选 1 小时 / 1 天 / 7 天）与长期公开地址，一键复制。
- **双击预览**：双击文件直接弹出预览窗口。文本类文件（txt / md / log / json / xml / yaml / csv / 常见代码与配置文件等约 50 种扩展名）按 UTF-8 显示内容并支持一键复制，图片（png / jpg / gif / webp / svg / bmp / ico / avif）直接显示。文本超过 1MB 或图片超过 20MB 时提示下载查看；其他类型双击会提示暂不支持预览。
- **在线编辑文本**：文本类文件可直接在预览窗口中修改并保存回 OSS，无需下载再上传。超过 500 KB 的文件自动降级为只读预览，并提示下载后编辑；图片及二进制文件不开放编辑。保存时按原文件的行尾风格（CRLF / LF）回写，不会因一次保存而改写整个文件的行尾。

### 设置

- 账号配置、常用路径、路径分类、上传设置四个分页，常用路径按账号分组管理并支持按分类筛选。
- **删除均有二次确认**：删除账号、常用路径或路径分类前都会弹出确认框，避免误操作。
- 删除账号会连带删除该账号下的全部常用路径，确认弹窗中会列出受影响的路径清单。
- 以上删除只影响本地保存的配置，**不会删除 OSS 上的任何文件**。

## 使用流程

1. 在“设置 > 账号配置”中添加 OSS 账号，填写 Endpoint、Region、AccessKey ID 和 AccessKey Secret。
2. 在“设置 > 常用路径”中选择账号，配置 Bucket、目录前缀、路径名称和备注。
3. 返回“上传中心”，选择 OSS 账号和一个或多个上传路径。
4. 添加文件或文件夹（文件夹可先选项目根目录，再在树形面板勾选版本 / 子目录），可按需填写子目录。
5. 点击开始上传（填写了子目录时会先弹出目标路径确认），上传过程可在右上角查看运行日志。
6. 在“OSS 文件”中按账号或预设路径浏览内容，可下载、删除、重命名、复制 / 移动对象，上传本地文件到当前目录，或双击文本、图片文件直接预览；文本文件还可在预览窗口中直接编辑保存（500 KB 以内）。

## 文本在线编辑

文本类文件可在预览窗口中直接修改并保存回 OSS，保存为覆盖写入，无需先下载再上传。

- **可编辑范围**：仅限文本类扩展名（与预览支持的类型一致），图片和二进制文件不开放编辑。
- **大小上限**：500 KB。超过上限的文件自动降级为只读预览，并提示下载后编辑；内容保存前会再次校验，避免绕过界面限制写入超大内容。
- **编码**：按 UTF-8 读取与回写。如果原文件是 GBK 等非 UTF-8 编码，打开时可能出现乱码，此时请下载后用本地编辑器处理。
- **行尾风格**：保存时沿用原文件的行尾（CRLF / LF），不会因为一次编辑而改写整个文件的行尾造成大范围 diff。
- **并发保护**：保存时会携带打开文件时取得的 ETag 做条件写入。若期间该对象已被其他人修改，保存会被拒绝并提示重新打开，避免静默覆盖对方的改动。
- **失败处理**：保存失败时弹窗保持打开、编辑内容不丢失，错误原因直接显示在弹窗内，可修正后重试。
- 保存成功后会自动刷新当前目录列表，文件大小与修改时间同步更新。

## 凭据安全

AccessKey Secret 不会以明文写入配置文件。应用使用 Electron `safeStorage` 调用操作系统提供的加密能力保存凭据；界面读取配置时只返回凭据是否已保存，不会返回 Secret 原文。

仍建议为本工具创建遵循最小权限原则的 RAM 用户，只授予实际需要访问的 Bucket 和操作权限。

## 开发环境

- Windows 10/11
- Node.js 20 或更高版本
- npm

安装依赖并启动开发环境：

```powershell
npm install
npm run dev
```

执行类型检查：

```powershell
npm run typecheck
```

生成生产构建：

```powershell
npm run build
```

## Windows 打包

双击项目根目录下的 `build.bat`，或在终端执行：

```powershell
build.bat --no-pause
```

脚本会自动安装依赖、执行类型检查和生产构建，并在 `release` 目录生成：

- `OSS Quick Upload Setup 0.1.0.exe`：Windows 安装程序。
- `OSS Quick Upload 0.1.0.exe`：免安装便携程序。

```text
OssUpload/
|-- src/
|   |-- main/              # Electron 主进程、OSS 请求及本地文件处理
|   |-- preload/           # 安全的渲染进程 IPC 桥接
|   |-- renderer/          # React 用户界面
|   `-- shared/            # 主进程与渲染进程共享类型
|-- pic/                   # 项目截图

|-- electron.vite.config.ts
|-- package.json
`-- README.md
```

| 命令 | 说明 |
