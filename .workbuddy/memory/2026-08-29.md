# 2026-08-29

## 修复：OSS 文件「预设路径」模式无法返回上级目录（08:45）

用户反馈：预设路径模式下「返回上级」只能进入子目录，到了预设根目录按钮就禁用，无法再往上看父目录。

**根因**：`BrowsePage.goUp` 里有两道硬限制——`if (currentPrefix === rootPrefix) return`，以及父级钳制 `parent.length >= rootPrefix.length ? parent : rootPrefix`。预设根目录被当成绝对上界。

**改动**（均在当前工作区，未提交）：

1. `src/renderer/src/App.tsx`（BrowsePage 内）
   - `goUp` 去掉上述两道限制，改为逐级 `split('/').slice(0,-1).join('/')`，可一直回到 Bucket 根目录；`currentPrefix` 为空时直接 return（按钮已禁用）。账号模式下 `currentPrefix === ''` 仍回 Bucket 列表。
   - 新增派生量（409-419 行）：`rootSegments` / `prefixSegments` / `withinPreset` / `crumbBase` / `crumbSegments` / `crumbRootLabel` / `crumbRootPrefix` / `canGoUp` / `goToCrumb(index)`。
     - `withinPreset = mode !== 'preset' || !rootPrefix || currentPrefix === rootPrefix || currentPrefix.startsWith(rootPrefix + '/')`
     - 在预设范围内时面包屑只显示相对段（基准为预设根），越出范围时显示 Bucket 内的绝对路径段。
   - 面包屑改为可点击路径：根按钮 + `ChevronRight` 分隔符 + 各级目录按钮（末级为不可点当前位置）。
   - 越出预设根时额外显示「预设路径外」标记 + 「回到预设路径」按钮（一键 `setCurrentPrefix(rootPrefix)`）。
   - 返回上级按钮 disabled 条件由 `atBucketList || (mode==='preset' && currentPrefix===rootPrefix)` 改为 `!canGoUp`（= `!atBucketList && Boolean(currentPrefix)`）。

2. `src/renderer/src/styles.css`：新增 `.crumb-path` / `.crumb-item` / `.crumb` / `.crumb-current` / `.crumb-hint` / `.crumb-flag`（越界黄色胶囊）。

**注意点**：上传栏「上传到 bucket/prefix/」与顶部 `oss://` 路径显示的都是 `currentPrefix` 真实值，越界后同步变化，无需额外处理；越界状态下上传仍按当前目录执行。

验证：`npm run typecheck` 通过。`npm run build` 仍被 WorkBuddy 安全删除 shim 拦在 `emptyDir(out/)`（环境已知问题，非代码问题）。
